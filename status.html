Services and status.

This page lists the services that run today. No uptime figures are measured or published for them.

Hosted services

  • aeoess.com. This website. Static pages.
  • gateway.aeoess.com. Reference gateway, used for our own testing. Access for others is through the Model Citizen pilot, by application.
  • mcp.aeoess.com. Remote bridge to the MCP server. Requires an access token.
  • api.aeoess.com. Mingle intent network.

Open source packages

The SDKs are published on npm and PyPI, and the MCP server on npm. They run on your own machine. Their availability depends on those registries, not on us.

Report a problem

Email signal@aeoess.com if a service is down. Send security issues to security@aeoess.com.

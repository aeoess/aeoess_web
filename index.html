One line, many machines. Every letter is a small drawing machine. The gaps between the words are machines too, and so are the three dials under them.

Drag anything to bend it. Tap it and it rings out to all the others. Tap a number to change a letter's machine, and the change is handed to the next letter. Let go of a dial and it rings out too.

What gets handed along only ever gets weaker. It never gains. Authority should work the same way.

Grown from a study of Tenfold by Ink & Switch.

aeoess lab

Agent Passport System defines authority. Governance OS enforces it. Agent Authority Conformance tests it. Mingle uses it.

  • Agent Passport SystemOpen protocol for verifiable agent authority. Cryptographic identity, scoped delegation, enforcement semantics and signed evidence for agents acting on behalf of people and organizations. Apache 2.0.
  • Governance OSEnforcement, evidence and visibility for AI agents. A gateway in the action path. It checks each action against the agent's authority before it runs, records a signed receipt, and shows authority, decisions and violations across your agents. Available through the Model Citizen pilot.
  • Agent Authority ConformanceOpen tests for whether agent authority holds across systems. Linux Foundation lab. Byte-level test vectors, negative cases and reproducible run reports, each labelled by who ran it. It reports what the evidence shows and issues no verdicts about products.
  • MingleFind people through your agent. Your agent knows you. Their agent knows them. Nobody sees a name until you both say yes. Open source and free.
